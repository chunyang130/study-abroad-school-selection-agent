# 範例對話：背景評估與初選落點（虛構學生、虛構學校）

> 以下示範 Agent 依 SKILL.md 的流程回覆。學生、學校、榜單案例與數字全部虛構。

---

**使用者：** 學生是私立大學資管系，GPA 3.45/4.0，TOEFL 今年 3 月考的，4.5 分，還沒考 GRE。想去美國讀資訊系統或商業分析，畢業想留美工作。

**Agent：**

**背景摘要**
- 私立大學資訊管理學系，GPA 3.45 / 4.0
- TOEFL 新制 4.5（2026/3 考，約等於舊制 86–94），GRE 未考
- 目標：美國碩士，資訊系統／商業分析，需 STEM 學程以利 OPT

**優勢**
- 本科與目標學程銜接直接，不需補先修（商業分析部分學程除外）
- GPA 達多數學程 3.0 門檻

**待補強**
- TOEFL 新制 4.5 落在 86–94 區間，遇到要求 100 的學程不足
- 沒有 GRE；部分商業分析學程「建議提交」
- 商業分析學程常要求微積分，需確認是否修過

**整體落點**：合適校為主，前 50 名學程列為夢幻。

**建議補強行動**
1. 12 月前再考一次 TOEFL，目標新制 5（約舊制 95–106）
2. 確認大學是否修過微積分，若無，申請 Example University B 前需補修

---

**初選表落點依據**（6 所：夢幻 2／合適 2／低風險 2）

| 分層 | 學校／學程 | 判斷依據 |
| --- | --- | --- |
| 夢幻 | Example University A — MS Information Systems | 榜單：國立大學資工 3.9/4.3、TOEFL 104 錄取同校 MS Computer Science 並標為夢幻，背景明顯強於學生；官網 TOEFL 100，學生新制 4.5 未達 |
| 夢幻 | Example University B — MS Business Analytics | 榜單：國立大學資管 3.6/4.3、TOEFL 98 錄取同校 MS Information Systems（夢幻），背景強於學生；官網要求微積分，學生缺 |
| 合適 | Example University C — MS Information Management | 榜單：私立大學資工 3.5/4.0、TOEFL 95 直接錄取同校 MS Data Science，背景相近；學生達官網 GPA 3.0、TOEFL 90 門檻 |
| 合適 | Example University D — MS Business Analytics | 榜單：國立科大資管 3.4/4.0、TOEFL 90 直接錄取；官網為新制 4.5，學生剛好達標，優勢不明顯 |
| 低風險 | Example University E — MS Information Systems | 榜單：私立大學資管 3.2/4.0、TOEFL 86 直接錄取，背景弱於學生；學生明顯高於官網門檻 |
| 低風險 | Example University F — MS Computer Information Systems | 榜單：私立大學資工 3.1/4.0、TOEFL 80 條件錄取同校 MS Computer Science；學生明顯高於官網 GPA 2.75 門檻 |

**標註說明**
- Example University F 的學費官網未列，表上寫「官網未列（見連結）」，未用其他網站補
- Example University D 的 Deadline 尚未公布 2027 入學版本，寫「預計2027/1/15」
- 各校科系排名若官方榜單未列，寫「官網未列」，不用排名整理網站的數字
